This repository contains MATLAB code for simulating microbial–metabolite interactions using a coupled system of Ordinary Differential Equations (ODEs). 

The code was developed to compare the effects of different microbial growth functions on predicted bacterial abundance and metabolite dynamics. Specifically, it compares:
*   Monod growth function
*   Liebig–Monod growth function
*   Additive growth function

*   The code was executed in MATLAB R2025a
